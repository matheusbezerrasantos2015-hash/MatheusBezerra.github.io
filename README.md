# 💼 Portfólio — Matheus Gabriel Bezerra

Bem-vindo ao meu portfólio pessoal!  
Este projeto foi desenvolvido para apresentar minhas habilidades, experiências e projetos na área de **Desenvolvimento de Software Multiplataforma (DSM)**.  
O design foi pensado para ser **clean, moderno, responsivo** e com suporte a **modo claro/escuro automático**. 🌗

---

## 🧩 Funcionalidades

✨ **Principais recursos do portfólio:**

- 🕒 Relógio digital (12h/24h)
- 🌙 Modo claro/escuro automático com opção manual
- 💡 Design moderno e responsivo (mobile e desktop)
- 🧠 Seção de habilidades técnicas com **barras de progresso**
- 💾 Botão de download direto do **Currículo (PDF)**
- 🧱 Cards interativos de projetos com links para o GitHub
- ⚡ Animações sutis ao rolar a página (scroll animation)
- 🔗 Footer com links rápidos (Email, LinkedIn, GitHub)
